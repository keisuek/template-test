# 売値チェッカー

商品の写真を撮ると、AI（Claude）が商品を特定し、web 検索でメルカリ・ヤフオク!の取引相場を調べて売値を推定する Web アプリです。

## 使い方

1. 静的ファイルとして配信する（例: `npx serve .` や GitHub Pages）。カメラ起動にはスマホで HTTPS が必要です。
2. 「設定」に [Anthropic API キー](https://console.anthropic.com/) を入力して保存（キーはブラウザの localStorage にのみ保存）。
3. 写真を撮影 / 選択し、必要なら状態などの補足を書いて「相場を調べる」。

## 表示内容

- 商品名・ブランド・型番・推定状態と確度
- メルカリ: 売れた価格帯 / 中央値 / 推奨出品価格 / 手数料10%差引後の手取り
- ヤフオク!: 落札価格帯 / 中央値 / 想定落札価格 / 手数料10%差引後の手取り
- 売り切れ・落札相場ページへのリンク、参照した情報源

## 仕組み

- `index.js` がブラウザから Anthropic TypeScript SDK（jsDelivr 経由）で `claude-opus-5-5` を呼び出します。
- 画像は長辺 1568px に縮小して送信。Claude は web 検索ツールで成約価格を調べ、JSON で結果を返します。
- 拒否時のサーバー側フォールバック（`fallbacks: "default"`）を有効にしています。

## 注意

- API キーをブラウザに置く個人利用向けの構成です。公開サービスにする場合は、API 呼び出しをサーバー側に移してください。
- 価格は AI による推定です。出品前にリンク先で最新の相場を確認してください。
